# Lokum

**Zintegrowany System Zarządzania Nieruchomościami Wynajmowanymi** Projekt inżynierski.

Lokum to system dla wynajmującego i jego najemców. Obejmuje cały cykl najmu: od podpisania umowy, przez naliczanie i pobieranie czynszu, zgłaszanie napraw i rozliczanie mediów, po zakończenie najmu i rozliczenie kaucji. Działa w dwóch aplikacjach, webowej i mobilnej, z tą samą funkcjonalnością dla każdej roli.
